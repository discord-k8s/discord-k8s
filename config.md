| **`workers`** (\*)  | _Object with properties:_<ul><li><code>chunking</code>: <code>'sequential' \| 'round-robin'</code> - Strategy used to chunk shards among workers<br /><br />**sequential**: Fill up each worker and then move to the next. `worker = floor(shard / shardsPerWorker)` e.g `[[0, 1, 2], [3, 4, 5], [6, 7, 8]]`<br />**round-robin**: Assign shards to workers evenly with interleave. `worker = shard % workerCount` e.g `[[0, 3, 6], [1, 4, 7], [2, 5, 8]]`</li></ul> _and_ _Object with properties:_<ul><li><b><code>mode</code></b> (\*): <code>'fit'</code> - Evenly split the number of shards among the numbers of workers. This can lead to a high number of shards in each worker if workers are not properly managed</li><li><b><code>count</code></b> (\*): <code>number</code> <i>or</i> <i>Object with properties:</i><ul><li><b><code>fromReplicas</code></b> (\*): <i>Object with properties:</i><ul><li><code>kind</code>: <code>'StatefulSet' \| 'Deployment' \| 'ReplicaSet'</code> - The kind of replica-based resource</li><li><b><code>name</code></b> (\*): <code>string</code> - The name of the resource</li><li><b><code>onChange</code></b> (\*): <i>Object with properties:</i><ul><li><code>action</code>: <code>'none' \| 'restart'</code> - Action to do when a change is detected. Restart will restart the orchestrator process when a change is detected. This will likely cause a reshard of all workers, restarting them. But useful for quick rebalancing</li><li><code>interval</code>: <code>number</code> - Interval to check the replica count for changes</li></ul> <i>or</i> <code>false</code></li></ul> - Fetch the number of replicas to use from a static resource that already exists in kubernetes</li></ul> - Amount of workers to manager. Can be an object defining a dynamic worker count</li></ul> _or_ _Object with properties:_<ul><li><code>kind</code>: <code>'StatefulSet' \| 'Deployment' \| 'ReplicaSet'</code> - The kind of replica-based resource</li><li><b><code>name</code></b> (\*): <code>string</code> - The name of the resource</li><li><b><code>mode</code></b> (\*): <code>'set'</code> - Calculate the number of workers based on the number of shards and set the replicas of a resource to that number.</li><li><code>shardsPerWorker</code>: <code>number</code> - Baseline number of shards to assign to each worker, shards per worker will never go over this number</li></ul> |
